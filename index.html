Running it

  • Windows: unzip anywhere and run the .exe. Keep the .pck and data_ folder next to it. SmartScreen warns because the game is not code signed: More info, then Run anyway.
  • Linux: unzip, chmod +x the binary, run it. Same rule about the .pck and data_ folder.
  • Android: arm64 phones only, landscape. Your phone will ask permission to install from this browser.
